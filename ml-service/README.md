# ML Service - Dual-Model Risk Engine

This standalone microservice provides machine learning predictions for the Animal Disease Traceability platform. It evaluates farm risk using two distinct models:
1. **Random Forest**: Analyzes the current snapshot of the farm to detect immediate anomalies.
2. **BiLSTM**: Analyzes the 14-day sequence of the farm to detect risky trajectories and trends over time.

Both models return a risk score (0-100%). The highest of the two is used as the overall risk score.

## Architecture

* **Framework**: FastAPI + Uvicorn
* **Dependencies**: Scikit-Learn (RF), PyTorch CPU (BiLSTM), Pandas, Numpy, Joblib
* **Data Sources**: Synthetic data generated by `generate_synthetic_data.py`.

## Quick Start

1. **Activate the virtual environment**:
   ```bash
   cd ml-service
   source venv/bin/activate
   ```

2. **Install dependencies**:
   ```bash
   pip install -r requirements.txt
   ```

3. **Generate Synthetic Data**:
   This generates `rf_training_data.csv` and `bilstm_sequences.npz` in the `data/` directory.
   ```bash
   python app/training/generate_synthetic_data.py
   ```

4. **Train Models**:
   Train both the Random Forest and BiLSTM models. They will be saved to `artifacts/`.
   ```bash
   python app/training/train_rf.py
   python app/training/train_bilstm.py
   ```

5. **Start the API Server**:
   ```bash
   uvicorn app.main:app --port 8001 --reload
   ```

## Endpoints

* `GET /health` - Readiness check to verify models are loaded successfully.
* `POST /predict` - Accepts a farm's current snapshot and 14-day history sequence to compute risk levels.

### Example Payload for `/predict`
```json
{
  "snapshot": { "sR": 0.8, "mR": 0.2, "dR": 0.0, "pF": 1.0, "lF": 0.5 },
  "sequence": [
    { "sR": 1.0, "mR": 0.0, "dR": 0.0, "pF": 1.0, "lF": 0.1 },
    ... // 14 total items
  ]
}
```
